# 04: Immersive Mode

**What to build:** You can read without distraction: in Immersive Mode everything except the Document's pages is hidden. The Reader opens with its UI showing, and scrolling never hides it. See `.scratch/reading/spec.md`.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] iOS/iPadOS: single tap on the page toggles Immersive Mode
- [ ] iOS/iPadOS Immersive Mode hides the navigation bar and status bar; home indicator fades automatically
- [ ] macOS: native full screen (⌃⌘F / green button) is Immersive Mode; toolbar hidden and shown when the pointer reaches the top edge
- [ ] macOS clicks never toggle Immersive Mode
- [ ] Scrolling never hides or shows the UI
